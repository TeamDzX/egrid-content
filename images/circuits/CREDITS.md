# Image credits

Every file in this folder is redistributed under a free licence, and every one
of these licences makes attribution a condition of that redistribution. This
file carries the attribution with the images themselves, so the copies remain
compliant independently of the app.

The same author, licence and source are also in `circuits.json`, which is what
the app renders over each photo. **If you replace an image, update both.**

Images are resized to a 1280 px long edge and saved as progressive JPEG at
quality 82 — sized for a 250 pt header at 3x, not for archival. The originals
are at the linked source pages.

Regenerate with `AppStore/../mirror` (see `content/README.md`).
